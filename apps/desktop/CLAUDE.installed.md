## This folder
The DJ Claude desktop app made this folder and keeps the rig in it. It is the project folder: run every command from here. (The user finds it again from the app: Settings shows the path, with "Open folder" and "Open Claude Code here".)

- **The sound system is the app's window**, not a browser tab: the app starts the server (the port is in `config.json`) and the audio engine by itself, with no "Start engine" click. If `node dj.mjs status` cannot reach the server, ask the user to open DJ Claude from the Start menu. `node dj.mjs start` runs the server without the app, with the page in a browser tab; only one of the two is the sound system at a time, and the other asks before it takes over.
- **Needs on the machine**: Node 20+, and ffmpeg / ffprobe on PATH. `node dj.mjs doctor` and the page at `/health` say what is missing. Stem separation (mashups, vocal maps) is installed with `node dj.mjs stems setup`, a download of about 600 MB: ask first. Recording video needs Playwright (see **dj-video**).
- **The user's, and yours to change**: `config.json` (the settings, also on the page at `/settings`), `data/` (everything the app makes: `data/dj/library/` is the music, downloads land in `data/dj/library/downloads/`; `data/dj/sets/`, cues, memory, sessions and `data/dj/exports/` beside it; `data/dj/cache/` is the analysis, decoded audio, stems and `server.log`, made again when deleted; `data/desktop/` is the window's place), `bin/` (yt-dlp, fetched on the first download), `.venv/` (the stem separator), `.claude/settings.json`, and any skill the user adds under `.claude/skills/`.
- **The app's, not to be edited**: `apps/` (the demo track list is `apps/server/demo-tracks/`), `tools/`, `dj.mjs`, this file and the skills the app came with. The app writes them again whenever it is updated, so a change made here is lost. If the user wants the rig itself to work differently, that is a change to its source (https://github.com/tomek-i/dj-claude), not to this folder.
- **Where things are**, when a skill names a file: the server is `apps/server/server.mjs` with its libraries in `apps/server/lib/`, the page is `apps/web/public/`, the CLI is `apps/cli/` (`node dj.mjs help`, `node dj.mjs help-engine`), the production tools are `tools/produce/`. There are no tests or benchmarks in this folder.
